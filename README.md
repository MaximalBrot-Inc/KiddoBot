## What is KiddoBot?

KiddoBot is a Discord bot written in Python. It is designed to be a fun and kinda useful bot for Discord servers.

It is currently in development and will be updated semi regularly.

It can either be self-hosted or you can invite it to your server by clicking [here](https://discord.com/api/oauth2/authorize?client_id=1061257711502770216&permissions=8&scope=bot)

## Requirements

a Discord bot token and some knowledge with Docker or Python


## Installation

### Docker

1. Download the [docker-compose.yml](docker-compose.yml) file
2. Create a new file called `data.txt` and paste your Discord bot token into it
3. Run `docker compose up` in the same directory
4. Enjoy!

### Python

1. Clone the repository
2. Create a new file called `data.txt` and paste your Discord bot token into it
3. Run `pip install -r requirements.txt`
4. Run `python KiddoBot.py`
5. Enjoy!
